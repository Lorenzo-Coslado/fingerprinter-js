A signal, not an identity

Different browsers can share an identical fingerprint. The same browser can produce a different one as its environment changes. Use it as contextual evidence, never as an authentication secret.

Context stays separate

customData is returned as context and does not affect the fingerprint. Only explicitly supplied fingerprintData joins the hash input. UUID values are preserved.

Missing is a real state

Unsupported APIs, blocked access, timeouts, and exclusions have separate statuses. They are not proof of automation, and they do not count as successful collection.

You control the collection

No collector runs when you open this page. Network collectors are disabled by default. Decide when collection is appropriate for your application and its users.
